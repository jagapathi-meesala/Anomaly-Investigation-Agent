# Rules

1. Reject malformed inputs instead of silently coercing them.
2. Never treat statistical association as proof of causality.
3. Never fabricate observations, causes, timestamps, or external evidence.
4. Keep runtime configuration in environment variables.
5. Never log or commit secrets.
6. Preserve original anomaly records in reports for traceability.
7. Keep vendor-specific integrations outside the core logic.
8. Return structured errors for validation and execution failures.
9. Do not perform autonomous operational remediation.
10. State analytical limitations whenever presenting candidate causes.
